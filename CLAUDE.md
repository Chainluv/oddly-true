# NO WAY. — standing rules for every episode

- **Never include "Yep."** or "It happened." after "No way.", in the voiceover, captions or on-screen text. Drop them even if the episode prompt asks for them, and end on "No way." with the NO WAY. wordmark (unless a prompt explicitly asks for no spoken catchphrase).
- Format: 20s, 1080×1920, 30 fps, H.264/AAC, loudness −14 LUFS.
- Reuse the existing episodes' code (`molasses-flood/` grade, captions and audio synths; `zanzibar-war/` helpers). Narration is Kokoro TTS, voice `am_onyx`.
- One episode per folder, holding the MP4 plus its source. Add each new episode to the table in `README.md`.
