# No Way — The Great Molasses Flood (1919)

`no-way-molasses-flood.mp4`: a 20s vertical short (1080×1920, 30 fps, H.264 + AAC, −14 LUFS), ready for TikTok, Reels and Shorts.

Everything is generated by code. There is no stock footage.

| File | What it makes |
|---|---|
| `street.py` | Ray-cast 1919 street: brick warehouses, cobblestones, trolley rails, elevated railway, molasses wave and flood |
| `tank.py` | Riveted storage tank: leak stains, spreading cracks, popping rivets, the burst |
| `paper.py` | Period newspaper front pages (fictional mastheads) with halftone photos |
| `aerial.py` | Tilted aerial view of the spill across the North End |
| `photo.py` | Parallax-layered black-and-white Boston waterfront "photograph" |
| `render.py` | Timeline, transitions, film grade, captions, title cards, glitch end card |
| `audio.py` | Synthesized score, sound effects, narration mix and ducking |

## Rebuild

```bash
pip install numpy pillow scipy soundfile kokoro-onnx
# fonts: @fontsource anton, unifrakturmaguntia, old-standard-tt, special-elite, playfair-display, oswald (.woff files)
export OT_FONTS=/path/to/fonts
# narration: Kokoro TTS (voice am_onyx) -> l1.wav..l5.wav (l5 = "No way.") in $VOICE_DIR
python3 render.py video.mp4
python3 audio.py $VOICE_DIR mix.wav
ffmpeg -i video.mp4 -i mix.wav -map 0:v -map 1:a -c:v libx264 -crf 22 -af loudnorm=I=-14:TP=-1.5 -c:a aac -b:a 256k out.mp4
```

Narration lines are listed in `render.py` (`CAPTIONS`) and timed by `NARR`.
